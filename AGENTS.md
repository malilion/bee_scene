# Visual acceptance

For frontend or 3D scene changes, read [.quality/WORKFLOW.md](.quality/WORKFLOW.md) and run its four-view independent review loop after each visual iteration. Completion requires a current approval with all four views scoring at least 9/10.

When `CODEX_QUALITY_ROLE` is `critic` or `repair`, follow that role's branch in the workflow; the parent process owns the loop.
